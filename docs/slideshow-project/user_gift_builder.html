كيف تنشئ هدية؟

افتح «اصنع هدية» أو «اختر هدية تحمل معنى». املأ البيانات التي تساعد المتجر على بناء اقتراح مناسب:

  • صلة المستلم: صديق، فرد من العائلة، شخص مقرّب، أو طالب/قارئ مبتدئ.
  • المناسبة: عيد ميلاد، نجاح أو تخرج، شكر وتقدير، أو بداية جديدة.
  • الميزانية: حتى 1,500 أو 3,000 أو 5,000 دج.
  • بيانات المستلم: اسم المستلم ورقم هاتفه، مع اختيار أجواء الهدية (دافئة، ملهمة، مشوقة، أو خيالية).
  • رسالة الهدية: رسالة قصيرة اختيارية ترفق مع الكتب.

الخطوات التالية

اضغط «شاهد اقتراح الهدية»، راجع الكتب المقترحة، ثم تابع إلى السلة. يمكن تعديل الاختيارات قبل تأكيد الطلب.

ملاحظة: رقم هاتف المستلم يصبح إلزاميًا عند إتمام طلب الهدية.
