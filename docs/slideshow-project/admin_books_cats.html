إدارة الكتب والتصنيفات

إدارة الكتب

اضغط «إضافة كتاب» لإنشاء منتج جديد، أو استخدم زر التعديل في صف الكتاب. املأ الحقول التالية:

البيانات الأساسية

  • رمز الكتاب، العنوان، التصنيف، الوصف، ورابط صورة الغلاف.
  • السعر بالدينار الجزائري والكمية المتاحة.
  • طريقة الاقتناء: «متوفر الآن» أو «يمكن اقتناؤه».
  • مدة الاقتناء عند الطلب: «في اليوم نفسه» أو «خلال يوم واحد».

الخصائص المتقدمة

  • وسوم الاكتشاف ووسوم الهدية، مفصولة بفواصل.
  • «قابل للإهداء»
  • «يظهر في اكتشف كتابك»
  • «إظهار ضمن الكتب المميزة»
  • «منشور للزوار»

إدارة التصنيفات

في تبويب «التصنيفات» استخدم «إضافة تصنيف»، أو عدّل/احذف تصنيفًا موجودًا.

عند إعادة تسمية تصنيف، تُحدّث الكتب المرتبطة به إلى الاسم الجديد تلقائيًا.

اضغط «حفظ»، ثم راجع بطاقة الكتاب في المتجر. استخدم «نسخ رابط الكتاب» لمشاركة رابط مباشر مع العملاء.
