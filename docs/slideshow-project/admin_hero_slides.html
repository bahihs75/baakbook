إدارة الـHero: إنشاء الشريحة وتنسيقها

في تبويب «إدارة الـHero»، اضغط «إضافة شريحة جديدة» أو عدّل شريحة قائمة.

النصوص والصورة

  • العنوان الرئيسي: نص بارز في الشريحة.
  • النصوص الفرعية: وصف قصير تحت العنوان.
  • رابط الصورة: URL لصورة الخلفية.

الأزرار (CTA)

  • الزر الأساسي: نص الزر ورابط توجيه.
  • الزر الثانوي: خيار اختياري بنص ورابط.

التنسيق البصري

  • لون النص: اختر فاتح أو داكن حسب الخلفية.
  • طبقة القراءة: خلفية شبه شفافة لوضوح النص.
  • الانعكاس: قلب الصورة أفقيًا عند الحاجة.

الحالة والترتيب

  • التفعيل: إظهار أو إخفاء الشريحة مؤقتًا.
  • الترتيب: تحريك الشريحة للأعلى أو الأسفل.
