إدارة الـHero: الإعدادات العامة

من تبويب «إدارة الـHero»، يتيح لك قسم الإعدادات العامة التحكم في سلوك ومظهر العارض الرئيسي قبل تفاصيل كل شريحة:

  • إظهار الـHero: تفعيل أو إخفاء العارض.
  • التبديل التلقائي: تشغيل الانتقال الآلي بين الشرائح.
  • مدة التبديل (ثوانٍ): تحديد زمن الانتقال لكل شريحة.
  • إيقاف التبديل عند التفاعل: الإيقاف عند تمرير الماوس.
  • إظهار مؤشرات الشرائح (Dots): عرض نقاط التنقل السفلية.
  • إظهار أسهم التنقل: عرض أسهم التنقل اليدوي.
  • ارتفاع الـHero: ضبط ارتفاع العارض ليتناسب مع العرض.
