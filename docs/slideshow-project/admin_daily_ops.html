الطلبات والتوصيل ومفاتيح الميزات

إدارة الطلبات

تابع الطلبات الجديدة وقم بتحديث حالتها لتبقى منظمة:

  • راجع تفاصيل العميل، بيانات الهدية، والكتب المطلوبة.
  • حدّث حالة الطلب: قيد المعالجة، مشحون، مكتمل، أو ملغى.
  • تأكد من توفر «الكتب التي يمكن اقتناؤها» قبل الشحن.

إعدادات التوصيل

اضبط رسوم الشحن لكل ولاية لضمان دقة الحساب في السلة:

  • أضف أو عدّل رسوم التوصيل للولايات المختلفة.
  • حدد تكلفة مكتب الاستلام.
  • حدد تكلفة التوصيل إلى المنزل.

مفاتيح الميزات

تحكم في ظهور أقسام المتجر بضغطة زر دون فقدان البيانات:

  • فعّل أو أوقف: اكتشف كتابك، اصنع هدية، كتب يمكن اقتناؤها، مختبر الأفكار، والبحث الذكي.
  • إيقاف الميزة يخفيها عن الزوار فورًا، لكنه يحفظ إعداداتك وكتبك السابقة.
