# سجل التحقق من تخطيط أزرار بطاقات الكتب

التاريخ: 2026-08-19

تمت إعادة تشغيل خادم المعاينة المحلي على المنفذ 8000 بعد تعديل `store.html`.

## النتيجة على سطح المكتب

ظهر في شبكة المنتجات صف أول يضم زرّي **اقتنه الآن** و**أضف للسلة** متجاورين، ثم ظهر زر **أهدِ هذا الكتاب** في صف ثانٍ بعرض البطاقة كاملًا.

## الفحص البرمجي

على البطاقة الأولى في المعاينة بعرض نافذة 1280px:

- شبكة الأزرار: `121.5px 121.5px`.
- عرض منطقة الأزرار: `251px`.
- زر أضف للسلة: عرض `122px` وارتفاع `42px`.
- زر اقتنه الآن: عرض `122px` وارتفاع `42px`.
- زر أهدِ هذا الكتاب: `grid-column: 1 / -1`، عرض `251px` وارتفاع `42px`.

## التجاوب على الشاشات الصغيرة

تم حذف قاعدة الهاتف التي كانت تحول شبكة الأزرار إلى عمود واحد. القاعدة الحالية تحافظ على عمودين متجاورين عند `max-width:520px`، وتثبت زر الإهداء على `grid-column:1/-1`، مع ارتفاع 42px وحشو أفقي صغير حتى تبقى العبارات واضحة.

## الاختبارات

أُجريت الاختبارات المحلية باستخدام `PYTHONPATH=.` بسبب أن بيئة الاختبار تحتاج مسار المشروع صراحةً عند الاستيراد. النتيجة: **12 اختبارًا ناجحًا**.

لم يتم تعديل GitHub أو PythonAnywhere أو `data.json` الحي، ولم يُنفَّذ أي `git push`.
