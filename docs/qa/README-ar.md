## تشغيل الفحوص الحالية

من جذر المشروع:

```bash
cd /home/ubuntu/baakbook-local/frontend
export FIREBASE_API_KEY='…'
export FIREBASE_AUTH_DOMAIN='baakbook-77c00.firebaseapp.com'
export FIREBASE_PROJECT_ID='baakbook-77c00'
export FIREBASE_STORAGE_BUCKET='baakbook-77c00.firebasestorage.app'
export FIREBASE_MESSAGING_SENDER_ID='446668891522'
export FIREBASE_APP_ID='1:446668891522:web:d381a6bfa453eb94abdb9b'
npm run build
cd ..
python3 scripts/validate_media_integration.py
git diff --check
```

يجب ألا تُكتب قيمة ImgBB في هذا الملف أو في أي ملف متتبع. تُدخل من تبويب «مكتبة الصور» في لوحة الإدارة، أو تُمرر كسرّ بيئي في اختبار محمي فقط.

## قالب حالة الاختبار

| الحقل | ما يجب تسجيله |
|---|---|
| المعرّف والمتطلب | مثل `ADM-015` و`MEDIA-UPLOAD` |
| الهدف والنطاق | ما الذي نتحقق منه، وما الذي لا نتحقق منه |
| الدور والبيئة | ضيف، مدير، Emulator، staging، production |
| الأولوية والشدة | P0–P3، ثم Critical/High/Medium/Low |
| الشروط المسبقة | الحساب، البيانات، الإعدادات، الاتصال |
| بيانات الاختبار | معرفات غير حقيقية، صورة اختبار، منطقة توصيل |
| الخطوات | خطوات مرقمة قابلة لإعادة التنفيذ |
| النتيجة المتوقعة | حالة الواجهة، Firestore، الشبكة، السجل |
| نتيجة فعلية ودليل | Pass/Fail، لقطة، trace، request id |
| التنظيف | حذف بيانات الاختبار أو إعادة الإعداد |
| التتبع | المتطلب، العيب، commit، pipeline |

## سياسة نتائج الاختبار

تُسجّل حالات P0 وP1 الفاشلة فورًا في تقرير الإصدار. ولا تُغلق الحالة إلا بعد إعادة تشغيلها في البيئة نفسها، وتسجيل الدليل، وفحص عدم وجود regression في الرحلة المرتبطة.

## اختبار رفع صورة ImgBB عمليًا

1. سجّل الدخول إلى `/admin.html` بحساب المدير.
2. افتح تبويب **مكتبة الصور**.
3. أدخل مفتاح ImgBB الذي يملكه المسؤول في حقل «مفتاح ImgBB» واضغط **حفظ المفتاح**. يُحفظ في `adminSecrets/imgbb` وفق قواعد Firestore المقيدة.
4. اختر صورة JPEG أو PNG أو WebP من حقل الملفات. الحد الحالي 12MB؛ تُضغط الصور الكبيرة تلقائيًا عند الإمكان، ويُمنع SVG الذي يحتوي عناصر تنفيذية غير آمنة.
5. اضغط **رفع الصور إلى ImgBB**. يرسل المتصفح الصورة إلى endpoint ImgBB الرسمي، ثم يحفظ Baak Books رابط الصورة وبياناتها الوصفية في `imageLibrary` بعد نجاح ImgBB فقط.
6. افتح الصورة من المكتبة، استخدم **نسخ الرابط** أو افتح **اختيار الصورة** من محرر كتاب أو شريحة Hero.
7. حذف الصورة من المكتبة يحذف سجل Baak Books فقط ولا يحذف الأصل من ImgBB؛ هذا السلوك يجب أن يظهر بوضوح في رسالة التأكيد.

## ملاحظة أمنية مهمة

الرفع المباشر يجعل مفتاح ImgBB حاضرًا في طلب المتصفح أثناء عملية الرفع؛ لذلك يجب أن يظل تبويب المكتبة محميًا بالمدير، وألا يُعاد استخدام المفتاح في مواقع أخرى. إذا تطلبت الحماية الأعلى، يكون المسار التالي هو نقل الرفع إلى Pages Function مع سر بيئي `IMGBB_API_KEY`، ثم منع وصول المتصفح إلى المفتاح تمامًا.
